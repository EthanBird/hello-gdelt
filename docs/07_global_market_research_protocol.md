# 07｜GDELT 全球新闻—多市场金融研究协议

版本：v1.0-pilot  
注册状态：结果生成前冻结  
研究分支：`agent/global-market-study-v1`

## 1. 研究目标

本研究检验 GDELT 新闻注意力、语调和异常冲击是否对全球金融资产的收益、波动与跨市场传导具有稳定、可复现、样本外增量解释力。研究对象覆盖 A 股、日本、韩国、美国股票，CME 期货，伦敦现货代理以及主要外汇对。

本协议明确区分：

- **确认性假设**：在读取最终结果前冻结；
- **探索性分析**：只用于生成下一轮假设，不得冒充确认性发现；
- **数据可行性结论**：可被裁决为 `SOURCE_FAILED` 或 `DATA_INSUFFICIENT`；
- **经济结论**：必须同时通过统计显著性、样本外增量、安慰剂和经济显著性门禁。

## 2. 第一阶段真实数据试验

试验期固定为 2025-07-01 至 2026-06-30。GDELT DOC 2.0 API 近一年搜索能力用于验证整个金融研究管线。最终长样本将转向 GDELT 2.0 Events/EventMentions/GKG 原始文件或 BigQuery 受控抽取。

第一阶段资产池包含：

- A 股指数与代表个股；
- 日经 225、丰田、索尼；
- KOSPI、三星电子、SK 海力士；
- 标普 500、纳斯达克 100、苹果、英伟达与能源 ETF；
- ES、NQ、CL、GC、HG；
- 伦敦黄金现货代理；
- EURUSD、USDJPY、USDKRW、USDCNY。

第一阶段 Yahoo Finance 数据只作为 C 级公开试验输入，不作为最终论文的唯一确认性行情源。最终研究优先采用交易所、监管机构、基准管理机构或有明确许可的数据供应商。

## 3. 新闻因子

首批 GDELT 因子：

1. 美国货币政策；
2. 全球地缘冲突；
3. 能源供应；
4. 通胀压力；
5. 中国增长；
6. 人工智能与半导体。

每个因子生成：

- 文章数量；
- 文章占 GDELT 同期全部监测文章的比例；
- 平均 Tone；
- 文章数量滚动异常值；
- Tone 滚动异常值。

为避免同日未来信息，试验阶段统一使用前一个 UTC 日的新闻桶。正式生产研究将采用交易所时区、盘前/盘中/盘后和夏令时感知的会话对齐。

## 4. 主要模型

### 4.1 收益模型

\[
r_{i,t+h}=\alpha+\beta N_{k,t-1}+\gamma r_{i,t-1}+\varepsilon_{i,t+h}
\]

其中 \(N_{k,t-1}\) 为新闻因子，\(h\in\{1,5\}\)。标准误使用 Newey-West/HAC。

### 4.2 波动代理模型

\[
|r_{i,t+h}|=\alpha+\beta N_{k,t-1}+\gamma |r_{i,t-1}|+\varepsilon_{i,t+h}
\]

### 4.3 样本外检验

采用 expanding-window walk-forward。每个增强模型与不含新闻变量的自回归基线比较：

\[
\Delta RMSE = \frac{RMSE_{baseline}-RMSE_{news}}{RMSE_{baseline}}
\]

只有 \(\Delta RMSE>0\) 才能宣称新闻具有样本外增量。

## 5. 多重检验与安慰剂

- 每个“新闻特征 × 目标 × horizon”家族内执行 BH-FDR；
- 另输出全局 BH-FDR；
- 时间循环移位保留新闻序列的自相关结构；
- 随机因子置换检验模型是否只是利用市场自身持续性；
- 所有随机检验固定种子并记录分布。

## 6. 裁决规则

`SUPPORTED` 必须同时满足：

1. 家族 q 值不高于 0.05；
2. 样本外 RMSE 改善为正；
3. 至少 60% 的滚动折方向一致；
4. 实际统计量优于 95% 安慰剂；
5. 样本量和条件数满足质量门槛。

不满足上述全部条件时不得称为已支持规律。显著但方向与单向预注册假设相反时为 `REJECTED`；其他情况为 `INCONCLUSIVE`。

## 7. 数据质量门禁

- 每项资产至少 150 个有效交易日；
- 不得跨缺失价格计算收益；
- 新闻与行情日期必须保留原始时间戳和对齐规则；
- 代理数据必须在资产名称和报告中显式标记；
- 数据下载失败不得用零值替代；
- 所有原始响应保存 SHA-256；
- 每个实验结果记录代码提交、配置版本和数据摘要。
