# GDELT 新闻状态与五类资产：1—20日局部投影探索 v1

该分析是在200项预注册线性检验之后执行，因此属于结果后探索，不能升级为确认性发现。

## 设计

- 新闻特征：美国总提及量、美国 Panic、印度 Panic、印度—美国 Tone 差；
- 资产：USD/INR、原油、黄金、美国10年期收益率、美元指数；
- horizon：1—20日；
- 目标：累计变化（RET）与累计变化绝对值（VOL）；
- 控制：五类资产当日变化、被解释资产当日绝对变化、星期效应；
- 推断：OLS + HAC，滞后阶数随 horizon 增加；
- 总系数：4×5×20×2 = 800；
- FDR：按新闻特征—目标族及全部目标族两级校正。

## 结果

| 指标 | 数量 |
|---|---:|
| 局部投影系数 | 800 |
| 名义 p<0.05 | 31 |
| 新闻特征—目标族 FDR q<0.05 | 0 |
| RET/VOL 全局 FDR q<0.05 | 0 |

## 名义路径

最强名义路径包括：

1. 美国 Panic 对黄金未来8—13日绝对累计变化的负系数；其中11日 β=-0.001648、p=0.00140，但目标族全局 q=0.315；
2. 美国总提及量对原油未来2—3日绝对累计变化的负系数；3日 β=-0.001837、p=0.00312，但全局 q=0.332；
3. 美国总提及量对DXY未来4—5日累计变化的正系数；5日 β=0.000487、p=0.0199，但全局 q=0.898；
4. 双边 Tone 差对黄金未来3—7日绝对累计变化的若干正系数，但完整FDR均不成立。

## 解释

连续多个名义显著 horizon 并不自动构成可靠的“冲击响应曲线”。相邻 horizon 的累计目标高度重叠，回归结果强相关；在资产、特征、目标和 horizon 四维搜索中，如果不执行曲线级或全局多重检验，很容易把一段连续的偶然偏离解释成持续性机制。

因此本探索只用于确定后续模型需求：最终报告需要基于原始 GDELT 事件类别预注册少量机制型响应曲线，并使用 simultaneous confidence bands、block bootstrap 或 max-t 校正，而不是逐点挑选显著 horizon。
